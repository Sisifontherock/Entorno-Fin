## Cómo abrirlos desde GitHub

1. Haz clic en uno de los dos enlaces de arriba.
2. En la página del archivo, pulsa **Download raw file** (el icono de descarga).
3. Abre el archivo descargado con tu navegador, por ejemplo Chrome o Edge.

**No necesitas instalar nada.** Cada archivo incluye su herramienta completa y funciona sin Internet. El progreso se guarda en el navegador que utilices. En CFA puedes exportarlo para conservar una copia.

## Qué hay en cada carpeta

- **`opciones/`**: juego visual de 14 estrategias, compras y ventas, explicaciones y todo su código.
- **`cfa/`**: estudio bilingüe de los módulos 1 y 2 de Portfolio Management, notas, fórmulas, preguntas, simulacros, seguimiento y todo su código.
- **`index.html`**: portada con botones para acceder a las dos herramientas cuando se sirve como web.

CFA se basa en el currículo 2025 proporcionado. Las preguntas son originales; el resultado de práctica no garantiza la nota oficial. Los módulos 3–6 se añadirán más adelante. Los PDF de referencia no están incluidos.

## Solo si quieres trabajar con el código

Desde la raíz: `npm start` abre un servidor de desarrollo en el puerto 8080; `npm test` valida ambos proyectos; `npm run build` regenera los dos archivos descargables. Las instrucciones específicas están en [opciones/README.md](opciones/README.md) y [cfa/README.md](cfa/README.md).
